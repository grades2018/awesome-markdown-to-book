# Awesome Markdown to Book [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of tools and resources for turning a Markdown manuscript into a finished EPUB, print PDF, or web book.

Markdown is a comfortable format for long manuscripts: plain text, easy to diff, and readable by many converters. Getting from a folder of chapters to a book a store will accept takes a few more steps, though. This list follows that path: draft or collect the text, build it into EPUB, PDF, or HTML, lay out print pages, then check the files before you upload them. Always proofread the final files on a real device or a printed proof before publishing.

⭐ = recommended pick.

## Drafting a Markdown Manuscript

Ways to get the book text itself into Markdown.

- ⭐ [ImagineYourBook](https://www.imagineyourbook.com/) - Writes a complete book draft (5,000 to 120,000 words) with a cover from one brief, then exports Markdown, Word, or EPUB, so the text can go straight into the builders below. Text only, no inside illustrations. $0 7-day trial (card required), then $24.99/month.
- [ghostwriter](https://ghostwriter.kde.org/) - Free, distraction-free Markdown editor from KDE with live preview and export.
- [iA Writer](https://ia.net/writer) - Focused Markdown editor for Mac, Windows, iPhone, and iPad.
- [Longform](https://github.com/kevboh/longform) - Obsidian plugin for writing novels and other long projects as scenes, then compiling them into one manuscript.
- [Manuskript](https://github.com/olivierkes/manuskript) - Open-source tool for writers with outlining, character and plot notes, and export through Pandoc.
- [Typora](https://typora.io/) - Markdown editor that hides the syntax while you type, with export to several formats.
- [Zettlr](https://www.zettlr.com/) - Open-source Markdown workbench for long writing projects, with Pandoc-based export.

## Book Builders

Turn Markdown files into EPUB, PDF, Word, or a web book.

- ⭐ [Pandoc](https://pandoc.org/) - Universal document converter, the usual engine for Markdown to EPUB, DOCX, and PDF.
- [Bookdown](https://bookdown.org/) - R package for writing books in R Markdown, with HTML, PDF, and e-book output.
- [Electric Book](https://github.com/electricbookworks/electric-book) - Jekyll template for producing print PDF, screen PDF, website, EPUB, and Word versions of a book.
- [HonKit](https://github.com/honkit/honkit) - Builds books from Markdown files, a maintained fork of the original GitBook tool.
- [Jupyter Book](https://jupyterbook.org/) - Builds publication-quality books from Markdown and notebooks.
- [Leanpub](https://leanpub.com/) - Publishing platform where authors can write in Markdown and publish ebooks in progress.
- [mdBook](https://github.com/rust-lang/mdBook) - Command-line tool that creates online books from Markdown, used for many technical books.
- [Quarto](https://quarto.org/docs/books/) - Pandoc-based publishing system that combines chapters into books in HTML, PDF, Word, and EPUB.
- [Vivliostyle CLI](https://github.com/vivliostyle/vivliostyle-cli) - Command-line tool that builds PDF and EPUB from Markdown or HTML with CSS typesetting.

## Templates

Starting points so you do not have to style a book from scratch.

- [Eisvogel](https://github.com/Wandmalfarbe/pandoc-latex-template) - Popular Pandoc LaTeX template for clean PDFs from Markdown, including a book layout.
- [Pandoc Book Template](https://github.com/wikiti/pandoc-book-template) - Simple project layout for building ebooks and documents from Markdown with Pandoc.
- [Pandoc Templates](https://github.com/jgm/pandoc-templates) - The default Pandoc templates, useful as a base for custom EPUB and PDF styles.

## Print Layout

Tools for paperback interiors and page planning.

- [Book Page Count Estimator](https://grades2018.github.io/book-page-count-estimator/) - Free browser tool that estimates paperback page count, KDP spine width, and full cover size from a word count. By this list's curator.
- [Paged.js](https://pagedjs.org/) - Open-source library that paginates HTML in the browser for print-ready PDF books.
- [VFM](https://github.com/vivliostyle/vfm) - Vivliostyle Flavored Markdown, a Markdown dialect and toolchain aimed at book typesetting.
- [WeasyPrint](https://weasyprint.org/) - Turns HTML and CSS into PDF, handy for print interiors built from Markdown converted to HTML.

## EPUB Checking and Fixing

Validate and repair files before upload.

- ⭐ [EPUBCheck](https://www.w3.org/publishing/epubcheck/) - Official W3C conformance checker for EPUB files.
- [calibre](https://calibre-ebook.com/) - Free e-book manager with conversion, metadata editing, and a built-in EPUB editor.
- [Kindle Previewer](https://www.amazon.com/Kindle-Previewer/b?ie=UTF8&node=21381691011) - Amazon's free desktop app for checking how a book will look on Kindle devices.
- [Sigil](https://sigil-ebook.com/) - Open-source EPUB editor for fixing markup, the table of contents, and metadata.
